# Manual Claim Checklist

1. Confirm route returns HTTP 200 consistently.
2. Run first-contact runner and save artifacts.
3. Run faucet adapter and save artifacts.
4. Capture exact claim wording, cooldowns, supported wallets, chains, and rate limits.
5. Confirm whether the path is form-only, wallet-gated, or action-capable.
6. Do not submit anything if requirements are ambiguous.
7. Record every visible prerequisite before any side effect.
8. If a claim attempt is considered, ask before executing it.
9. After any manual action, capture resulting proof URLs, tx hashes, or receipts if they exist.
10. Update evidence template immediately.
