# Manual Wallet Connect Checklist

1. Confirm route returns HTTP 200 consistently.
2. Run first-contact runner and save artifacts.
3. Run wallet adapter and save artifacts.
4. Capture supported chains, wallet brands, and exact connect/sign wording.
5. Determine whether the flow is informational auth or transaction-capable.
6. Do not connect or sign automatically.
7. If signing is requested, capture the exact message/prompt before approving anything.
8. Preserve screenshots or raw snapshots of the connect gate if possible.
9. Record whether the action would expose an address, session, or onchain permission.
10. Update evidence template immediately.
